# Fashion Image ANN

A small image-classification project that uses a PyTorch artificial neural network (ANN) to classify clothing images.

## Files

- `fashion_ann_model.ipynb` - notebook with data loading, model training, and evaluation.
- `fmnist_small.csv` - image data with a `label` column and 784 pixel-value columns.

## Requirements

The notebook uses Python with:

- pandas
- scikit-learn
- PyTorch
- matplotlib

Install the packages in your Python environment, then open and run `fashion_ann_model.ipynb` in Jupyter Notebook or VS Code. The notebook expects `fmnist_small.csv` to be in the project directory.
